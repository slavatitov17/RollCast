| Условие | Единицы измерения | Описание |
| --- | --- | --- |
| Общее время | мин | Числовой горизонт переводится в секунды и рассчитывается полностью, даже если металл затвердел раньше или еще не затвердел. «Авто» ищет полное затвердевание всех пяти участков по пункту 11. По умолчанию «Авто». Числовой диапазон 0,06–21600 мин; дополнительно действуют ограничения числа кадров и памяти. |
| Шаг по времени, Δt_max | с | Максимальный временной шаг неявной схемы пункта 7. По умолчанию 30 с, диапазон 0,01–3600 с. Число шагов округляется вверх, действительный равномерный шаг не превышает введенный. Уменьшение шага используется для проверки сходимости. |
| Шаг по диаметру, ΔD | мм | Задает число металлических колец в пункте 4. По умолчанию 1 мм, диапазон 0,1–1000 мм. Реальный радиальный шаг не превышает половины диаметрального. Число колец каждого металлического участка ограничено диапазоном 2–4096. Сетку оснастки это поле не меняет. |
