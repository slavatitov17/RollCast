# RollCast

## Назначение

RollCast — учебная программа для моделирования затвердевания монолитного прокатного валка после заполнения формы при сифонной заливке.

Модель предусматривает четыре цилиндрических отделения: нижнюю шейку, бочку, верхнюю шейку и прибыль. Тепло отводится радиально через песчаную форму и металлическую опоку в окружающую среду. Торцы теплоизолированы. Для демонстрационного проекта используются условные исходные данные.

## Текущая версия

На первом этапе реализовано запускаемое окно Windows с заголовком RollCast и пустой светло-серой рабочей областью.

## Технологический стек

- C++20 — язык исходного кода.
- Win32 — создание окна и обработка системных сообщений.
- GDI — оформление рабочей области окна.
- CMake — конфигурация сборки.
- MinGW-w64 — компилятор и средства сборки для Windows.

## Установка и запуск

Для сборки нужны Windows, CMake версии 3.20 или новее и инструменты MinGW-w64 `g++` и `mingw32-make` в `PATH`. Откройте PowerShell в корневой папке проекта.

```powershell
cmake -S . -B build -G "MinGW Makefiles" # Настраивает сборку проекта с MinGW-w64.
cmake --build build # Собирает исполняемый файл в каталоге build.
.\build\RollCast.exe # Запускает приложение RollCast.
```

Для прямой сборки через `g++` выполните следующие команды в той же папке.

```powershell
New-Item -ItemType Directory -Force -Path build | Out-Null # Создаёт каталог для исполняемого файла.
g++ -std=c++20 -DUNICODE -municode -mwindows -static-libgcc -static-libstdc++ src/main.cpp -o build/RollCast.exe -luser32 -lgdi32 # Собирает приложение с библиотеками Windows.
```

## Работа с программой

После запуска открывается главное окно. Его можно перемещать, изменять его размер, сворачивать и закрывать стандартными средствами Windows.

## Примечания к расчётной постановке

Расчётное время отсчитывается от конца заполнения формы. Заливка предусмотрена как анимация. Для каждого отделения принят постоянный геометрический объём. Металл в сифоне учитывается в изображении заливки, а итоговый объём относится к четырём отделениям валка и прибыли. Жидкий объём прибыли и время её полного затвердевания входят в запланированные результаты расчёта.
